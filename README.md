# New Bombay Sandwich, Bharuch

One-page site for New Bombay Sandwich, EVON Chowk, Bharuch. Designed and built by Prime Digitals.

Plain HTML, CSS and JS. No build step. Open `index.html` or serve the folder.

- `js/menu-data.js` holds the menu (15 sections, prices in ₹)
- `js/main.js` holds shop details, the menu board, and the motion (GSAP + ScrollTrigger, Lenis)
- `assets/` holds the photos. These are stock images for now and will be replaced with the shop's own photos.
